```text
In game theory, there is a famous paradox:
"You don't need to defeat your counterpart to win the tournament."

To test this, I built Episode 2 of The Dilemma Experiment: an open-source Python simulation running round-robin multi-agent tournaments.

We pitted 5 behavioral archetypes against each other:
1. Always Cooperate (Unconditional Altruism)
2. Always Defect (Pure Exploitation)
3. Tit-for-Tat (Immediate Reciprocity)
4. Grim Trigger (Permanent Retaliation after 1 betrayal)
5. Random (Coin-flip Chaos)

The results from our simulation engine were startling:

The pure predator (Always Defect) won 8 individual duels and lost 0. It beat every single agent head-to-head.
Yet on the society leaderboard, it finished at Rank #7.

Meanwhile, Tit-for-Tat won ZERO duels (0 wins, 7 ties, 2 losses).
Yet it outperformed the predator by over 130 cumulative points.

Why?
Predators win the battle, but convert every subsequent interaction into mutual defection (1 point/round).
Reciprocal agents tie or lose slightly against predators, but generate compounding mutual wealth (3 points/round) with everyone else.

Systems Architecture Highlights:
• Immutable Population model with strict strategy instance isolation (ADR-011)
• Deterministic N*(N-1)/2 round-robin scheduler (ADR-012)
• 102 passing zero-mock unit tests
```
